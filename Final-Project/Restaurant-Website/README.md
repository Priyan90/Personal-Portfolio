# 🍽️ Spice Garden - Restaurant Website

## 📌 Project Overview

Spice Garden is a modern, responsive restaurant website developed as a final web development project.

The website provides information about the restaurant, displays a food menu, and allows users to book a table through an interactive booking form.

---

## 🎯 Project Objectives

- Create a complete multi-page business website
- Build a responsive and modern user interface
- Add navigation between multiple pages
- Display restaurant information and menu items
- Create an online table booking form
- Implement JavaScript form validation
- Add interactive menu cards
- Use localStorage for booking data
- Follow basic accessibility and semantic HTML practices

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
